# Hovdemo v3

En strukturert, selvstendig demo bygget med funksjoner fra HovslagerSystem og bilder fra tidligere hovdemo.

## Start
Åpne `index.html` direkte i nettleseren, eller kjør en enkel lokal webserver:

```bash
python3 -m http.server 8080
```

Åpne deretter `http://localhost:8080`.

## Innhold
- Norsk, svensk og engelsk språk
- Dashboard og hurtigstart
- Kunde-, heste-, jobb- og prisregister
- Hovkontroll og behandling
- Bildegalleri og stor bildevisning
- Faktura, betalingsstatus og utskrift/PDF
- Jobbrapporter med bilder
- Firmainnstillinger
- Lokal lagring i nettleseren
- Mobiltilpasset grensesnitt
